Занимаюсь backend-разработкой на C# и ASP.NET Core: разрабатываю REST API, реализую бизнес-логику и работаю с базами данных.
Также создаю веб-интерфейсы на React и настольные приложения на WPF и Avalonia.

### Технологии

**Backend** — C#, .NET, ASP.NET Core Web API, Entity Framework Core, JWT

**Базы данных** — PostgreSQL, SQL Server, Redis, KeyDB

**Frontend** — JavaScript, TypeScript, React

**Desktop** — WPF, Avalonia UI, XAML

**Инструменты** — Git, Docker, Swagger/OpenAPI, Postman

### Проекты

- **Dormitory Management System** — full-stack система управления студенческим общежитием на ASP.NET Core и React.
- **IT School CRM** — CRM для взаимодействия с образовательными организациями, командный хакатонный проект.
- **FSP Platform** — платформа подбора и оценки кандидатов, командный хакатонный проект.
- **Desktop-приложения** — системы управления кинотеатром и фотоцентром на WPF и SQL Server.
